# Моушен-ролик «Авто запчасти сёстрам»

Вертикальный ролик 9:16, 1080×1920, 30 fps, 15 секунд, со звуком: `avto-zapchasti-sestram-reel.mp4`.

**Важно:** это черновик. Канал `t.me/avto_zapchasti_sestram` из облачного окружения был недоступен, поэтому
ролик собран по названию канала, а не по его постам. Фирменные цвета, тексты и конкретные обещания
нужно сверить с каналом. Все тексты лежат в объекте `COPY` в начале `index.html`.

## Сценарий (128 BPM, 32 бита = 15 с)

| Время | Сцена |
|---|---|
| 0,0–2,8 с | Тахометр, мигает лампа. «ЗАГОРЕЛАСЬ ЛАМПОЧКА?» → глитч → «БЕЗ ПАНИКИ.» |
| 2,8–6,6 с | Тормозной диск с суппортом, вокруг вылетают запчасти. Название канала |
| 6,6–9,4 с | «ТУТ ТЫ НАЙДЁШЬ»: три карточки с иконками |
| 9,4–11,3 с | Бегущие строки с категориями запчастей, «ВСЁ ДЛЯ ТВОЕЙ МАШИНЫ» |
| 11,3–15,0 с | Призыв: ник канала, кнопка «ПОДПИСАТЬСЯ», тап, «ПОДПИСАНО», конфетти |

Что стоит проверить и заменить на реальное: подписи карточек (`COPY.cards`), список категорий (`COPY.words`),
слоган, цвета (`const C`).

## Просмотр

Открыть `index.html` в браузере (нужны соседние файлы `fonts/`).
Пробел — пауза, ←/→ — покадрово, `?t=5.2` — открыть на секунде 5,2, `?clean` — без подсказки.

## Пересборка MP4

```bash
npm i playwright            # один раз; нужен Chromium (npx playwright install chromium)
python3 audio.py            # numpy → audio.wav (бит, свуши, поп-звуки, аккорд подписки)
node render.cjs             # кадры → ffmpeg → avto-zapchasti-sestram-reel.mp4 (~2 мин)

# отдельные кадры для проверки:
node render.cjs --frames 40,180,300 --out /tmp/shots
```

Нужны `ffmpeg`, Node 18+, Python 3 с `numpy`. Если Chromium лежит не в стандартном месте,
укажите путь в переменной `CHROMIUM_PATH`. Таймлайн в `index.html` и `audio.py` общий
(`B` = длина бита), поэтому при смене длительности сцен правьте оба файла.

Шрифты Unbounded и Montserrat (SIL OFL) лежат в `fonts/`.
