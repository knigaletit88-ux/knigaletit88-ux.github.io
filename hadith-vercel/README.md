# 🌿 Бот «Энциклопедия хадисов» на Vercel

Бесплатный вариант бота без сервера: Telegram присылает сообщения на адрес Vercel, а код в
`api/webhook.js` отвечает. Зависимостей нет, данные берутся с сайта мини-приложения
(`https://knigaletit88-ux.github.io/hadith/data/ru`, при недоступности — из API HadeethEnc.com).

**Что умеет:**
- `/start` — приветствие «السلام عليكم ورحمة الله وبركاته» и кнопка «Открыть энциклопедию»;
- 🌅 `/today` — хадис дня (тот же, что в мини-приложении), 🎲 `/random` — случайный хадис;
- любое слово — поиск, номер хадиса — сам хадис;
- под хадисом: «Разъяснение и польза» и «Карточка» (открывают мини-приложение), «Поделиться», «Ещё хадис»;
- inline-режим: в любом чате `@Hadis_1234bot слово`.

## Как задеплоить (5 минут, с телефона тоже можно)

1. Зайдите на [vercel.com](https://vercel.com) → **Sign Up** → **Continue with GitHub**.
2. **Add New… → Project** → выберите репозиторий `knigaletit88-ux.github.io` → **Import**.
   Если его нет в списке — нажмите **Adjust GitHub App Permissions** и дайте доступ к нему.
3. В настройках перед деплоем:
   - **Root Directory** → **Edit** → выберите папку `hadith-vercel`;
   - **Framework Preset** — `Other`;
   - **Environment Variables**: имя `BOT_TOKEN`, значение — токен от @BotFather.
4. Нажмите **Deploy** и дождитесь конфетти 🎉.
5. Откройте в браузере `https://<имя-проекта>.vercel.app/api/setup` — появится «✅ Бот подключён».
6. Отправьте боту `/start`.

Токен хранится только в настройках Vercel — в репозиторий его добавлять нельзя.
Если токен поменяли: Vercel → Settings → Environment Variables → изменить `BOT_TOKEN` → Deployments → Redeploy → снова открыть `/api/setup`.

## Настройки (необязательно)

| Переменная | Что значит | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен бота (обязательно) | — |
| `BOT_USERNAME` | Имя бота без @ | берётся из Telegram |
| `APP_URL` | Адрес мини-приложения | `https://knigaletit88-ux.github.io/hadith/` |
| `DATA_URL` | Откуда брать хадисы | `https://knigaletit88-ux.github.io/hadith/data/ru` |

## Проверка

```bash
cd hadith-vercel
npm test
```

Тесты используют настоящие данные из `hadith/data` и имитацию Telegram.

> Python-версия бота (`hadith-bot/`) нужна только при запуске на своём сервере. Если бот работает
> через Vercel, запускать `bot.py` с тем же токеном нельзя: Telegram отдаёт сообщения либо вебхуку,
> либо программе с опросом, но не обоим сразу.
